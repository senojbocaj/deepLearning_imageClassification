# deepLearning_imageClassification
In this project, I explored and optimized Multilayer Perceptron (MLP) and Convolutional Neural Network (CNN) architectures on the MNIST and CIFAR-10 benchmark datasets using Python and PyTorch. I built and evaluated custom model designs from scratch, implementing systematic hyperparameter tuning across 10 to 20 configurations per architecture to analyze how network depth and learning parameters impact performance. By leveraging validation-based model selection and fine-tuning with the Adam optimizer, I successfully identified peak configurations that minimized overfitting and maximized classification accuracy across both image sets.
